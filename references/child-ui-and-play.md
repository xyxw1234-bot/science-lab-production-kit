# 儿童界面与因果玩法规格

## 1. 布局骨架与可操作空间
馆级导航固定在顶部居中，各馆为同级入口，不把某馆藏进另一馆课程步骤。顶部导航与底部或侧边工具上下紧凑，中间主要空间给模型、运动路径和可辨结果。全屏透明布局容器不截获模型手势，只有真实控件区域响应点击。不能用宽幅说明卡、重复 HUD、常驻任务清单把科学对象挤成背景。

Pad 与 PC 的同组选择维持一排；手机保留一排局部横向滚动，不让整个页面横向漂移或把按钮折成多行盖住场景。测试首项与末项均可触达，内容较少时相对屏幕居中。馆切换可以回到默认滚动位置，同馆调参不得把按钮轨道反复复位。横屏手机须重新安排工具和观察区域，而非按桌面比例缩小。

主触点以至少 44×44 CSS 像素为套件硬性验收规范；这是本套件操作下限，不宣称所有设备均因此可用。视觉 glyph 可小，实际 hit area 必须足够且不与邻控件重叠。必要状态、按下态、焦点态和禁用原因可见；纯图标须有儿童能懂的名字和可访问名称。补充操作不能挤走启动、暂停、重置、返回全貌及声音控制。

## 2. 控件按因果而非按字段排布
每个场景确定一个主动作和少量当前必要变量。连续量使用可拖动滑条并显示单位与当前值；离散对象使用短标签选择。不要给每个滑条再铺一排增减、预设、确认、应用按钮。调参何时生效须明确：立即生效，或下次实验生效；不能画面停留旧值而数字先变。

点按、拖动、键盘替代操作共享状态入口。拖动必须处理 pointer capture、pointercancel、失焦、隐藏和导航，不能松手后仍持续移动。相机操作与对象操作有可辨规则，命中模型前先验证画布没有被透明层遮挡。镜头自动适配仅在入场、明确聚焦、重置或必要的尺度变化发生；不每帧夺走儿童的观察角度。

重置恢复声明过的初始参数、位置、时钟、负载与镜头，不清掉无关声音偏好；重置按钮旁可用短语说明范围。比较功能明确保持条件，结果以轨迹、位置、时间、亮度、转速等可辨差异呈现，不能仅靠小字“成功”。颜色不是唯一信息通道，静音也仍保留所有结果线索。

## 3. 因果游戏五问的落地表
每场景填写并在可运行样本上验收：①目标：儿童想让世界发生什么；②操作：点、拖、转、放开什么；③即时视觉与声音反馈：状态变化怎样被察觉；④可辨结果：如何知道与上次不同；⑤再玩理由：能换什么条件或组合。五项不能都靠旁白回答。

例如发电带灯、风扇和车：目标是使负载工作；操作是改变输入或负载；反馈是对应结构运动、亮度和经过语音避让的反馈声；结果是供电足够与不足时的输出差异；再玩理由是在输入相同时比较负载。声音表达交互或机制，不把真空环境配成有空气传播的环境声。默认不添加积分、排行榜、签到与分享成就来替代再探索。

宇宙跳跃的趣味来自同样起跳在不同重力下的轨迹和落点；火箭来自连续推力与燃料限制的可预期挑战。不能按一下就任意设置速度，或用隐形规则把结果硬改成胜利。人体风险场景的目标是识别、求助与安全理解，不能设置模拟对真人做危险动作的挑战。

## 4. 儿童语言与自然分层
默认短句使用“转得更快”“电够不够”“空气走哪条路”等动作词。先让孩子看见变化，再给必要解释；重要对象的名字保持稳定，不以拟人化称呼替换真实身份。一至二年级可直接操作看主要关系，三至四年级在同场展开变量、量纲和对照；入口不问年龄、不强制选择难度、不降低完整因果。

技术解释、公式与详细来源后置到可展开面板，但模拟边界在相关位置即时可见，例如“时间加快了”“颜色帮助我们看清，不是真实颜色”。不得把限制全部藏在成人条款，也不能把所有技术文字常驻画面。未经批准不加观察册、账号、留下一刻、积分与社交入口；先保证看懂、做得到和愿意再试。

## 5. 界面验收合同

测试者在不读成人说明的条件下识别主动作，并演示一次改变条件和一次恢复全貌。若须依赖旁人逐步指路，记录为可发现性问题，不用新增更多按钮作为默认修复。优先调整对象反馈、标签和工具层级，再邀请儿童复测。
六个视口逐一检查：PC 1440×1000、Pad 横 1024×768、Pad 竖 820×1180、手机 390×844、短手机 360×640、横手机 844×390。每个视口覆盖初始、变化极值、工具展开、错误与重试、视频返回、切馆及重置。量取导航中心、主触点、工具占位和实际投影边界；不能只检查静态首屏。

每个可达选项用真实 mouse 与 touch 事件至少执行一次，确认命中目标、最新状态和新渲染版本；已选项不变应记录为合法无操作。检查旋转、缩放、滚动与模型拖动的冲突。画面截图、自动化事件和声音证据分别留存；自动化通过不意味着儿童觉得好玩。另以儿童试用记录迷路点、误操作、解释与主动重玩，且实机触感和浏览器模拟报告分开。
