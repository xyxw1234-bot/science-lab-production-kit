# 科学建模与真实资产规格

## 1. 一份事实，两类模型
每个场景分开登记“来源参考”和“教学模拟”。来源参考记录扫描、测量、真实模型、图片或摄影纹理；教学模拟记录自行构建的结构、运动与可视化。优先寻找许可明确的真实资产，不以几何块拼成的外观替代需要识别的真实模型。简化结构可以用于明确标识的机制解释，但不得借真实来源的名字宣称其细节经过扫描或测量。

模型说明必须给出假设、方程或算法、变量与单位、有效范围、初始条件、误差或验证范围、不能推断的结论。时间压缩、距离压缩、独立放大、符号颜色与流动粒子分别声明；二维切片不是三维体数据，深度堆栈不是时间序列，外表扫描不自动提供真实内部结构。真实网格也不自动证明动力学可靠。

## 2. 可追溯资产清单
逐文件记录 asset_id、来源机构与原始链接、作者、版本或采集日期、取得日期、许可全文或快照、署名、允许的使用及修改条件、原始与发布文件哈希、格式、转换步骤和工具版本。开源代码许可不等于模型、纹理、声音和图片许可；混合资源逐件核查，授权不明的关键资产不能发布。

几何另记原始单位、发布单位、坐标系、上下与前向轴、原点、缩放、完整变换链、部件 identity 和源编号。用已知物理尺寸交叉校准，单位不明时不得展示精确测量。转换前后核对有效顶点属性、索引、材质和层级；图像保存原图尺寸、色彩或通道、裁切、日期及对象身份。不能仅因文件名相似就合并两个来源身份。

## 3. 数值与画面必须独立验证
物理函数在 CPU 上测试量纲、零点、极值、单调性、边界、守恒或已声明的损耗与步长收敛。独立参考计算不得调用被测函数得出相同答案。记录输入、误差容限依据与实际输出，不把少量样点说成全域精度证明。

渲染验证必须读取实际发布模型、世界矩阵、实例矩阵及真正绘制的三角形，不接受只查包围盒、隐藏代理或诊断数字。接触验收覆盖整面及面内点，不只顶点；对于贴地体须检查实际地表三角形与上方体的间隙、穿透和相交边。对声称为实体的模型检查闭合体积、定向边、正体积和顶点邻域；开放薄片、裁掉 drawRange 或双面材质不能冒充封闭体。

关节验证实际轴、枢轴、父子变换、运动范围和连接端点。检查齿数与转速比、共轴传动、轮子方向、软组织与骨架归属，不能仅看“都在转”。剖切恢复须保持源材质和姿态；壳体开门后必须确实可见内部而非另一层实心盒。几何与性能分开验收：低帧率不能靠删除科学必需结构掩盖，几何正确也不等于设备运行顺畅。

## 4. 四类代表机制的最低合同
宇宙跳跃：同一质量、起跳速度和初始高度下比较重力；明确是否忽略空气阻力。位置与速度积分使用同一时钟，落地插值与接触地面一致。连续跳跃从已落地位置累积；空中输入可排队或拒绝并解释，不能瞬移回原点。低重力轨迹与落点须在可恢复全景中看见。

发电带负载：输入机械功、转换损耗、电压电流或已声明的等效模型、负载功率及输出动作相互一致。灯亮度、风扇转速、车运动由同一能量状态驱动；供电不足、停机、全局暂停均有真实结果。发电、传输、储能与用电关系在完整世界可见，禁止凭一段装饰电流动画声称计算了真实电场。

火箭：推力是力而不是速度旋钮。至少实现质量与剩余燃料、推力方向、重力、加速度、速度和位置的连续更新；声明固定质量或变质量近似及推力适用条件。有燃烧才按流率耗燃料；无燃料不得继续产生同样推力；关机后在模型外力下保留惯性。测试零推力、失重近似、燃料耗尽和不同时间步；轨迹、喷焰、速度显示不能互相矛盾。

食物误入气道：区分消化与呼吸通路、吞咽保护、气道阻塞和正常通气；教学高亮不冒充临床影像。观察和虚拟操作不得转为对真人施力或试吞危险物。紧急处理仅采用经审核、地区与适用对象明确的权威材料，不自行生成儿童照做的急救操作教程。

## 5. 证据对应与发布前输出

每项科学断言建立证据对应表：断言文本、来源页段、模型字段、画面对象、验证方法和剩余限制逐一关联。参考不足时缩小断言或停止该项开发，不用漂亮画面补齐缺失事实。修改坐标、尺度、网格或方程后，原证据不能直接沿用，须按影响范围重新运行并保留版本差异。
提交版本化模型卡、逐文件资产清单、独立数值测试、实际三角形几何审计和 GPU 画面证据。记录下载、解析、构建、首帧、稳定帧率与峰值驻留各自成本，并说明测试环境；模拟视口或受限容器结果不能宣称低配实机保证。任何未验证尺度、来源缺项或科学争议须进入阻断清单，不得仅在页脚写“仅供参考”后继续精确断言。
