# 工程、验证与发布规格

## 1. 自包含交付和责任边界
项目应在取得公开说明的依赖后独立构建与运行，不依赖专用私有技能、个人机器路径或固定服务器。提供依赖锁、构建与运行命令、配置示例、模型和媒体清单、来源及许可、状态契约、测试入口、发布说明与回滚方法。外部 AI 服务是显式可选依赖，缺失时阻断实时 AI，不影响已声明可离线运行的核心实验；不得将密钥写入代码、日志、构建产物或浏览器。

多 agent 协作先划定单写者文件域，再约定状态字段、事件、单位、资源所有权和验收输出。物理计算、渲染、界面、音频可分域，但必须消费同一权威快照。跨域变更先更新接口契约和迁移测试，不能各自维护一份“当前速度”。所有异步构建、加载、讲解与预取均有 generation 和取消逻辑，离开后不能回写旧任务。

## 2. new 与 iterate 两条流程
new：冻结主题及完整探索地图→获取来源与风险审查→设计完整世界和代表性场景→做可运行纵向切片→审科学、模型、界面、声音、玩法→通过后扩展主题→全覆盖验证→候选发布→批准晋升。

iterate：盘点现有路由、资产、来源、状态和证据→备份稳定版及目标指针→界定保留项与改变项→另做代表性候选→评审后逐步扩展→回归原有有效机制→候选验证→获批晋升。现有项目不能自动被认作标杆。强烈负评触发冻结原版，保留稳定入口并单独提供候选，不因自动化全绿而覆盖，也不在候选默认放晋升按钮。

## 3. 生命周期与有限资源
主内容首个可交互帧不等待非必要参考和全部馆预载。区分下载、解压、解析、构建、首帧、参考就绪；无法获取总量时不用虚假百分比。加载失败提供可真实执行的重试，模块导入失败后须验证恢复机制确实重新加载而非重复命中失败缓存。

缓存分编码文件、CPU 场景和 GPU 驻留三层，明确容量及淘汰策略，度量唯一缓冲区、纹理估算和构建峰值。不无限保留所有场景，也不每次回访重建仍在预算内的对象。前台优先于预取，后台失败不能抢占全局错误或镜头。构建并发受限，快速切换以最后选择为准；dispose 释放监听、观察器、控制器、几何、材质、纹理、阴影目标和音频资源。失败的半成品也必须清理。

## 4. 六视口与真实行为矩阵
固定视口：PC 1440×1000、Pad 横 1024×768、Pad 竖 820×1180、手机 390×844、短手机 360×640、横手机 844×390。每个可达场景及选项建立 scene×viewport×action 清单；脚本聚合实际条目与预期条目，缺项写未测，不能以截图数量充覆盖率。

每视口实际执行 mouse 与 touch 输入，确认命中、状态和新渲染帧，检查视觉、声音、重置、冷加载、暂停恢复、切馆、视频返回、运行时 console/shader 错误。另覆盖网络失败及恢复重试、旧响应、断流、连续切换、重复进入及资源回收。涉及拖动先确认 elementFromPoint 命中画布，再验证实际位移，不用注入内部状态替代输入旅程。

科学数值、实际三角形接触与体积检查、真实 GPU 画面、声音播放、来源许可、依赖网络和部署字节各有独立证据。自动化证据、真实儿童试用和物理 device 实机记录分开标注；模拟视口不等于实机，截图不等于声音可听，CPU 测试不等于渲染正确。资源受限导致未测时报告阻断，不伪造性能或成功记录。

## 5. 可审计发布与稳定入口
部署目标由项目自己的配置提供，包含环境名、目标目录或服务、候选入口、稳定入口和健康检查，禁止固定私人服务器。构建产物生成文件清单与哈希；每次发布使用不可变 release 标识，记录源码提交、tag、构建工具、依赖锁和配置版本。main 保持可审计稳定，候选在独立分支或发布空间，批准后才进入稳定路径；稳定链接不随每次版本换名。

发布前验证候选依赖闭包、资源字节和来源。部署后读取准确目标：从外部入口下载清单及关键资源比对哈希，并在公开可达页面走真实交互、声音解锁、冷加载和网络失败/重试。上传成功、HTTP 200 或本地通过都不算公开验证。切换稳定指针须防并发、原子执行并记录旧值；任何公开验证失败恢复旧指针，再读回确认，不能编辑旧不可变发布掩盖差异。

## 6. 完成判定

配置示例只使用占位符，并说明哪些字段由部署者提供。发布前扫描源代码、产物、来源清单及测试日志中的凭据与个人信息；发现秘密立即阻断并轮换相关凭据，不以删除一行日志视为补救完成。公开证据保留必要技术事实，内部追踪编号与儿童原始资料按授权范围隔离。
交付报告列“已实现、已验证、未验证、阻断”，附证据路径、版本、环境与时间。验收标准逐项对照，不以计划全部完成代替产品通过。任何保留的简化、缺少服务、版权限制、缺少医学或儿童试用必须明示。最终清单包含源代码、可运行构建、测试及证据、资产来源、模型边界、媒体审核和可执行回滚说明；不把未经验证的学习收益、数字孪生精度或设备保证作为交付结论。
