# 审查量表与证据门禁

## 1. 使用规则与评审输出
本量表用于代表性场景审查、扩展验收与发布审计。先查硬否决，再评质量；高分不能抵消否决。每项填写状态（通过/失败/未测/不适用）、实际版本、证据、审核人和遗留问题。不适用必须解释理由，不能用来跳过核心场景。自动化可证明具体断言，不能自动保证科学可信、儿童安全、审美或好玩。

评审结论分为阻断、限于候选、允许扩展、允许发布。允许扩展只说明代表性方向可继续，不等于所有主题已经通过。允许发布需命名验收范围与批准人。建议权重用于组织讨论，不是实测学习指标、儿童偏好模型或行业认证。

## 2. 硬否决清单
以下任一成立即停止相关发布；涉及共同运行时或系统性风险时停止整个版本：

- 关键科学因果错误、没有惯性与燃料约束却把任意速度赋值叫推力模拟、数值和画面不一致，或把模拟说成测量。
- 用几何块替代要求的真实模型并冒充扫描；资产身份、许可、来源或发布文件哈希不可追溯；把引擎开源许可当作资产授权。
- CPU 数字通过却实际渲染穿透、悬空、错轴；声称实体却只有开壳；接触仅查顶点，遗漏面内穿透；重要结构删减而未声明。
- 鼓励儿童对真人执行危险动作，或急救操作缺权威原始来源、日期、地区、适用范围与 approved 人工审核。
- 固定脚本冒充实时 AI；缺服务仍假称智能理解；前端暴露 token；未经授权默认采集麦克风或儿童录音。
- 首讲与字幕不同稿、同页调参不断打断重播、切页旧音持续、过期 AI 回写；视频返回丢失原场景状态且未批准改变合同。
- 主动作无法触达、主触点低于 44×44 CSS 像素、关键错误态无有效重试、暂停仍继续物理演化或重置未回到声明状态。
- 核心路径运行时或 shader 报错、关键资源失败却显示成功、发布地址未实测、已知严重回归未修、无可用回滚。
- 强制课程通关冒充自由探索；未经批准覆盖冻结的稳定版；用虚构测试、儿童试用或实机结论替代缺失证据。

门禁失败记录复现步骤、影响面、修复责任与复测证据；旧失败记录保留，不能覆盖文件后宣称从未失败。对尚未完成的医学、版权或设备审查，结论只能是待审，不得视为默认通过。

## 3. 建议评分框架
通过硬门禁后，建议采用五项权重：科学与模型可信度 30%，因果玩法与探索深度 25%，儿童界面及视觉理解 20%，导师声音与媒体 10%，工程稳定和交付证据 15%。这些权重是建议，不是实测结论；项目可在评审前调整并留版本，禁止看完结果再调权重掩盖弱项。

各项按 0—4 级：0 无实现；1 有展示但核心链不成立；2 主链可用但有明显缺口；3 在规定边界内完整并有证据；4 在 3 的基础上，经独立复核且提供丰富而不混乱的比较或迁移。加权结果仅辅助排序，不设能自动放行的万能总分。记录每项最弱场景，避免优秀场景的平均值掩盖未完成主题。

科学看完整世界、结构、因果、变量和比较是否衔接，以及独立数值、真实三角形、来源及界限。玩法看目标、操作、即时视觉与声音反馈、可辨结果、再玩理由五问能否在交互中被体验。界面看顶居中同级导航、紧凑工具、模型空间、六视口重排、局部滚动与手势。导师看 ready 首讲、同源字幕、控制权、真实 AI 和安全；工程看生命周期、运行时、失败恢复及可审计发布。

## 4. 必须人工判断的项目
科学专业复核：简化是否保留关键机制，来源能支持哪些断言，单位和误差解释是否恰当。医学风险由适格专业人员审核，代码测试不能承担签署。版权审核逐资产处理，不把来源链接本身视为授权。

儿童语言和审美：词语是否懂、对象是否可辨、视觉是否压迫或迷路、音量是否舒适、真实纹理是否适合对象。玩法体验：孩子是否知道能做什么、能解释一个变化、是否愿意主动再试。不能由点击次数、停留时间或自动截图推断好玩，更不能凭一次试用声称普遍学习有效。

试用记录须区分年级范围、招募与监护授权、任务条件、观察原话和研究者解释，避免收集不必要身份信息。保留失败、犹豫与求助，不只选成功片段；以最小化、去标识方式归档。测试人员引导太多时要注明，不能算自主发现。

## 5. 证据包和结论模板
证据分四栏：自动化断言与环境；真实浏览器视觉及声音人工复核；真实儿童试用；物理 device 实机运行。六视口仅属于浏览器覆盖，不自动进入设备栏。每份证据关联场景、动作、输入、预期、实际、版本、来源和日期；截图须标明初始或极值，不用一帧证明整个运动。

最终表述模板：“本版本在所列范围通过哪些检查；仍有什么未测；人工审核由谁完成；稳定入口与 release/tag 是什么；可否扩展或发布；回滚目标是什么。”若只有自动测试则明确写“未证明儿童偏好与实机表现”。强负评后冻结原版、仅审候选，不能用量表分数否认真实体验问题。
