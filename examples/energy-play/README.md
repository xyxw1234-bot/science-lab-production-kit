# 发电带动负载：可运行工程管线示例

这是一个独立小型参考，不是完整能源实验室、实物发电机模型、校准求解器或已认可的高拟真美术模板。图形为自建原理示意，不用它替代正式主题的精细模型。

## 启动

在仓库根目录：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory examples/energy-play
node --test examples/energy-play/*.test.mjs
```

浏览器打开 `http://127.0.0.1:8765/`；该本地地址仅用于实际运行，不是公共发布或远程依赖。

## 孩子操作

点击立即进入，导师自动讲解；按住摇柄，灯亮、风扇转。松开后有惯性与衰减。试着增加一个负载，比较同样输入下的状态。支持鼠标、触摸、Space/Enter按住，以及松开/取消/失焦清理。曲线不是主要结果。

场景切换触发对应新讲解，同场景改负载/复位不重启语音。声音与实验音效独立，支持重播、暂停。音频播放失败会给出字幕与重试提示，不显示假成功。`Mentor`的适配器可以被项目接入审核音轨/可用TTS；本例没有实时AI服务，也不会把固定文本叫作实时推理。

## 科学边界

`model.mjs`为原创建模：角速度由输入力矩、摩擦和电磁反力矩积分；简化直流电势与角速度成正比，内阻与并联负载决定电流/端电压。电磁机械功率与电输出加内阻损失在该近似下相等。灯为电阻近似；风扇转速是随供电变化的教学映射，不是完整电机方程。无实物校准和温度模型，不输出测量结论。

## 导师音频

中文文本位于 `audio/scripts.json`，字幕与播放脚本取同一数据。音频为对这些原创文本生成的预合成语音，使用 Edge TTS 7.3.1 / zh-CN-YunxiNeural，不是自然人声音克隆，也不是实时问答。音轨/哈希/时长见 `audio/provenance.json`。它们用于管线参考；正式项目的声音选型及商用/再分发范围应依所用服务现行条款核验，不能把本仓库文本许可当作服务音色授权。需要独立授权声音时，按相同文本重生成或录制，再核文本/字幕/音轨一致。

## 测试边界

Node测试覆盖数值和叙述调度的控制流；真正浏览器的输入、音频时间推进、像素差异、视口与错误检查须另留证。模拟视口不是物理设备认证，文件时长或能播放不等于人耳完整试听。无需API密钥，不收集录音或个人信息。
